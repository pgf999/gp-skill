# 技术指标正确使用手册

LLM 做技术面分析时必须遵循的口径。重点在**指标的正确解读**和**常见误用**——很多散户把指标当圣经，这里要反着来。

## 均线（MA / EMA）

**用途**：趋势方向、支撑/阻力、多空切换

**默认参数**：MA5 / MA10 / MA20 / MA60 / MA120 / MA250

**正确解读**：
- 多头排列（5>10>20>60）= 健康上涨
- 空头排列 = 健康下跌
- 粘连 = 趋势将启动（但方向未定）
- 均线向上发散 = 趋势加速
- 股价跌破 20 日均线但 60 日均线仍向上 = 回调，不是反转

**误用**：
- ❌ "金叉就买，死叉就卖"——在震荡市会被来回打脸
- ❌ 只看一根均线做决定
- ✅ 金叉 + 成交量放大 + 位置（非高位）= 才有意义

## MACD

**默认参数**：EMA12 / EMA26 / DEA 9

**正确解读**：
- DIFF 和 DEA 的相对位置表示动量
- 零轴上方金叉 = 多头加强
- 零轴下方金叉 = 反弹，不一定是反转
- 柱状放大 = 动能增强
- 顶背离（价创新高但 MACD 没创新高）= 趋势衰竭信号
- 底背离 = 止跌信号

**误用**：
- ❌ 震荡市频繁金叉死叉，全当信号会破产
- ✅ 日线 MACD 看大势，60 分钟线 MACD 看买点

## RSI

**默认参数**：14 日

**正确解读**：
- 0-30：超卖区，不等于马上涨，可能继续跌
- 70-100：超买区，不等于马上跌，可能继续涨
- 强势上涨时 RSI 可长期维持 > 70
- RSI 在 40-70 之间波动 = 健康趋势

**误用**（最常见）：
- ❌ "RSI < 30 就是买点" —— 大跌初期 RSI 可能连续一个月在 30 以下
- ❌ "RSI > 70 就是顶" —— 强势股 RSI 可以 80+ 持续数周
- ✅ 配合背离 + 其他信号

## KDJ

**默认参数**：9,3,3

**正确解读**：
- 类似 RSI，但更敏感（震荡更剧烈）
- J 值 > 100 超买、< 0 超卖
- 低位金叉较可靠，高位死叉较可靠
- 日线 KDJ 在强势中大部分时间钝化（持续 > 80），别被吓到

**误用**：
- ❌ 把 KDJ 单独用。它对噪音太敏感。
- ✅ 一般和 MACD 交叉使用：MACD 定方向，KDJ 找买卖点

## 布林带（BOLL）

**默认参数**：20, 2（标准差）

**正确解读**：
- 中轨 = 20 日均线 = 多空分界
- 上下轨 = ±2 标准差
- 价格触及下轨 = 超卖但可能继续下行
- 价格突破上轨 = 强势但不一定是卖点（强趋势会沿上轨运行）
- 带宽收窄 = 波动率压缩，即将变盘

**误用**：
- ❌ "碰上轨就卖，碰下轨就买"——在趋势市会大幅错过机会
- ✅ 用于判断"正常波动区间"+ 结合趋势方向

## 成交量

**远比价格指标重要**。价格会骗人，成交量不会（除非有做假）。

**基础组合**：
- 价涨量增：健康
- 价涨量缩：警惕背离，可能是主力出货前的反弹
- 价跌量增：空方凶猛
- 价跌量缩：抛压减轻，可能止跌
- 极端放量（> 20 日均量 3 倍以上）= 多空分歧剧烈，次日方向重要
- 极端缩量 = 没人交易，行情暂时休眠

**指标**：
- VR（成交量比率）
- OBV（能量潮）
- 量比（今日成交量 / 5 日均量）

## ATR（平均真实波动幅度）

**默认参数**：14 日

**用途**：衡量波动幅度，用于设置**基于波动的止损**

例如：设置止损 = 当前价 - 2×ATR。这样的止损不容易被正常波动打爆，只在真正跌破时触发。

**本 skill 建议**：止损设置 = max(固定百分比止损, 价格 - 2×ATR)，取更宽那个，避免噪音。

## 资金流指标

**主力资金净流入 / 北向资金**：
- 非常 A 股特色的参考，理论上反映机构动作
- 口径：超大单 + 大单 买入 - 卖出
- 持续 3 天以上净流入 + 股价上涨 = 较强信号
- 单日大幅流入但股价下跌 = 小心反手出货陷阱

**龙虎榜**：
- 出现在龙虎榜的票次日波动放大
- 机构买入 + 游资跟风 = 中短期看好
- 游资主导 + 机构卖出 = 投机盘，不建议跟

## 形态识别

LLM 自己靠 K 线数据识别复杂形态不太准，以下几种是相对可靠的：

**较为可靠**：
- 箱体突破（价格创 N 日新高 + 放量）
- 阶梯上涨（每轮高点和低点都比上一轮高）
- 跳空缺口（缺口后强度通常延续几天）

**不可靠但散户爱用**：
- 头肩顶/底 —— 事后看图很漂亮，实时判断误差大
- 各种"形态学"三角形 —— 震荡市充满假突破
- 江恩角度线 —— 玄学成分大

## 组合使用建议

**日线级别的分析套餐**（本 skill 默认）：
1. 均线系统判断主方向
2. MACD 判断动能阶段
3. RSI 排除超买超卖极端区
4. 成交量验证信号强弱
5. ATR 设动态止损

**短线买点**（在主方向向上的大前提下）：
- 回踩 20 日均线不破 + KDJ 低位金叉 + 量价配合

**短线卖点**（在持仓盈利后）：
- 上影长阴 + 成交量放大 + MACD 顶背离

## 对 LLM 的硬性要求

1. **永远**要指明指标的**计算周期**（5 日？20 日？）
2. **永远**结合至少 2 个维度给信号（纯技术面 + 基本面 / 趋势 + 量能）
3. **永远**给出信号的置信度
4. **永远**说明"在什么情况下这个信号会失效"
5. **不要**把单一指标的信号当作独立决策依据
