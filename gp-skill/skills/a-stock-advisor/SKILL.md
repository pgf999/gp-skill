# A股投资决策支持

## 简介
对单只 A 股或自选股池进行技术面（均线/MACD/RSI/量价）+ 基本面（ROE/PE/PB/营收净利同比）+ 资金流（主力净流入）+ 业绩预告的综合评分，输出带置信度的买卖信号、买入区间、止损止盈位和建议仓位。同时内置风控闸门（ST 过滤、追涨预警、小盘股提示），帮助用户把纪律固化到流程而非靠情绪判断。

## 触发词
- 帮我分析 XXXXXX（6位股票代码）
- 推荐几只值得买的股票 / 自选股里有没有机会
- 看看我的自选股 / 扫描一下股票池
- 该不该买 / 该不该卖 / 有没有买点
- 帮我加/删自选股
- 止损位在哪 / 仓位建议
- 分析持仓健康度

## 使用限制
- 仅覆盖 A 股（沪深主板/创业板/科创板/北交所），不支持港股、美股
- 不预测股价；所有信号均为概率性判断，不构成投资建议
- 实时数据依赖网络：无网络时仅可使用缓存（最多 6 小时有效）
- 真实下单功能默认关闭，需用户在 `config/risk.yaml` 中显式开启 `execution_mode: live`

## 技术要求
- Python 版本：3.10+
- 依赖（均可 pip 直接安装）：
  - `akshare`（免费，基础数据源，无需注册）
  - `tushare>=1.3.0`（可选，推荐；需 `TUSHARE_TOKEN` 环境变量）
  - `pandas`, `numpy`, `pyyaml`, `requests`
- 不自行管理 API Key：Tushare token 通过 `TUSHARE_TOKEN` 环境变量注入，`TUSHARE_HTTP_URL` 可指定中继地址（可选）
- 可选加速：`mootdx`（TDX 协议），`duckdb`（本地 K 线缓存）

## 输出格式

**单股分析（成功）：**
```
综合评分: 0.641 | 动作: buy | 置信度: 100%
收盘: 38.90 | 日期: 2026-05-07 | 持仓周期: 短线(<1月)

【价格区间】买入: 36.02~38.90  止损: 36.18  止盈: 46.68
【建议仓位】12%

【正面信号】均线多头排列 / 主力净流入16亿 / 营收同比+10%
【风险点】PE偏高(41.6) / 净利同比-33%
【警告】⚠ 流通市值偏小，波动剧烈
```

**自选股推荐（成功）：**
Markdown 表格 + 每只股票的展开分析卡

**失败时：**
```
ERROR: No OHLCV data for '999999' — 代码不存在或已退市
```
或
```
WARN: watchlist 为空，请编辑 config/watchlist.yaml
```

## 注意事项
- 修改 `config/risk.yaml`（仓位上限、止损比例）前须告知用户改动内容
- 真实下单须用户明确回复「确认」，Skill 不会自动提交订单
- 不 hardcode 任何 token / 密码；凭据必须通过环境变量或 host 注入
- ST / *ST / 退市整理股可以分析但不会给出买入建议
- 所有买卖建议强制附带反面理由（避免单边叙事）
