## 关键硬约束触发

### 硬约束 #4：绝对止损
- **配置值**：`stop_loss.absolute_stop_loss = -0.05`（-5%）
- **触发规则**：每只股票持仓亏损 ≥ -5% 时，生成强制卖出信号
- **应用**：
  - 000858（五粮液）：买 200 → 现 180，亏损 -10%，**触发**，必须卖出
  - 600519（贵州茅台）：买 1600 → 现 1409.5，亏损 -13.09%，触发止损线（1600 × 95% = 1520），**触发**，必须卖出

### 止盈线参考
- **配置值**：`take_profit = 0.15`（+15%）
- **应用**：两只票均未触发止盈条件，不适用

## 行业集中度检查
- **配置上限**：`position.max_sector_ratio = 0.30`（30%）
- **检测**：600519 和 000858 均为白酒龙头（消费酒水赛道），相当于用户在单一行业 double-down
- **风险判定**：行业过度集中，同步下跌风险明显

## 风控纪律（principles.md）
- **顶层纪律 #1**：本金第一 ✓ 应用（建议卖出防止进一步亏损）
- **顶层纪律 #2**：止损不容讨论 ✓ 应用（不能说"再观察"）
- **顶层纪律 #5**：不全仓单一股票 ✓ 应用（指出行业集中度风险）
- **卖出条件 #1**：当前价相对买入价亏损 ≥ 绝对止损线 ✓ 触发
