# 投资方法论速查卡

提炼自格雷厄姆《聪明的投资者》、利弗莫尔《股票作手回忆录》、彼得·林奇《彼得林奇的成功投资》、霍华德·马克斯《投资最重要的事》、塔勒布《反脆弱》、江恩《股市操作法》、以及大量 A 股实战经验。不是"按这个做就能赚钱"，而是"违背这些一定会亏"——是**幸存者规则**。

## 0. 三句话总纲

1. 保住本金永远是第一规则，赚钱是第二规则
2. 市场永远比你聪明；你最大的优势是可以不交易
3. 系统性纪律打败天才灵感——长期看一定是这样

---

## 一、仓位与资金管理（最重要，排第一位）

### 1.1 凯利公式约束版
经典凯利公式在实盘过于激进。用 **半凯利** 或 **四分之一凯利** 起步。本 skill 的保守档直接用 1/4 凯利。

### 1.2 单只股票仓位上限
- 保守：≤ 10%
- 稳健：≤ 20%  
- 激进：≤ 30%
- **永远不要** 单只股票超过 40%。即使你觉得"这只绝对不会错"——尤其是当你这么觉得的时候。

### 1.3 总仓位与现金比例
- 牛市晚期（估值高、情绪热）：降到 50% 以下
- 震荡市：60-80%
- 熊市末期（估值低、情绪冷）：可以接近满仓
- **永远保留至少 10% 现金**，机会来时没弹药是最痛的

### 1.4 加仓与减仓
- **只对盈利的仓位加仓**，不要对亏损的仓位加仓摊薄（利弗莫尔：对亏钱的股票加仓是散户最大的坟墓）
- 加仓应**递减**：第一次加 50%、第二次 30%、第三次 20%，不是等比放大
- 减仓可以分批，但**触发止损必须一次清空**

## 二、买入纪律

### 2.1 买入前 checklist（每项都要能回答 yes）

- [ ] 我知道为什么买它（说清楚基本面/技术面/事件驱动，三选一至少说清一样）
- [ ] 我知道买错了止损在哪（数字必须能说出）
- [ ] 我知道赚钱后止盈在哪（可以是目标价，也可以是移动止盈）
- [ ] 如果股价跌了 20% 我不会加仓（写下来）
- [ ] 我没在追一个已经连涨 5 天的股票
- [ ] 这笔买入后，我的单只持仓和总仓位都没超限
- [ ] 我不是听别人说的，我有独立判断

不满足任何一项都不要买。

### 2.2 好的买点特征（综合技术面）
- **突破买点**：向上突破重要阻力（如 20 日高点），放量
- **回踩买点**：趋势向上的票回踩 20/60 日均线不破，缩量企稳
- **超跌反弹**：严重超卖（RSI < 20 且 KDJ 底背离），有基本面支撑
- **业绩催化**：财报超预期发布当日的缺口跳空，业绩持续性可验证

### 2.3 永远不买的情况
- ST / *ST / 退市整理 / 立案调查 / 重大违规
- 连续涨停后的"追板"（T+1 你一定在第二天吃跌停）
- 高送转炒作尾声（通常除权后补跌）
- 财务造假嫌疑（突然巨额资产减值、实控人减持同步）
- 你自己都不相信自己买入理由的时候

## 三、卖出纪律（比买入还重要）

彼得·林奇说过："卖出比买入难 10 倍"。

### 3.1 强制卖出情形（不讨论，直接卖）

1. **触发止损线**（绝对止损 或 移动止损）—— 不要找理由"再观察一天"
2. **基本面大幅恶化**（财报暴雷、重大诉讼、实控人出事）
3. **当初买入逻辑证伪**（比如买入理由是 Q4 业绩好转，结果 Q4 业绩不及预期）
4. **公司出现造假证据**（第一时间清仓，不等官方调查）
5. **ST / *ST 警示**

### 3.2 建议卖出情形（评估后决策）

1. 触发止盈目标
2. 出现更好的机会（机会成本考量）
3. 技术面明显破位（跌破关键均线且不反弹）
4. 板块/行业出现系统性逆风
5. 持有超过 12 个月但股价没有新高

### 3.3 卖出的心理陷阱

- **处置效应**：倾向于卖盈利票、留亏损票。正确做法正好反过来。
- **锚定效应**：以买入价为锚，跌 5% 慌了，涨 50% 得意——价格不在乎你的成本价。
- **沉没成本**：已经亏的钱不是"等它回来"的理由。只看"从此刻起，这钱放哪里预期收益最高"。

## 四、选股框架（分成价值、成长、交易三类，不要混）

### 4.1 价值型（格雷厄姆 / 巴菲特 / 霍华德·马克斯）

**筛选指标**：
- PE < 行业中位数 × 0.7 且 < 历史 30% 分位
- PB < 2（高 ROE 公司可放宽）
- ROE 最近 5 年均值 ≥ 12%
- 毛利率稳定（波动幅度 < 20%）
- 资产负债率 < 60%（金融业除外）
- 分红连续 3 年
- 自由现金流为正

**持仓周期**：至少 12 个月，很多时候是 3-5 年

### 4.2 成长型（彼得·林奇）

**PEG = PE / 盈利增速**
- PEG < 1 是彼得·林奇的核心筛选线
- 盈利增速看未来 3 年预期，不能只看过去一年
- 收入增速 > 行业平均 1.5 倍
- 毛利率稳定或提升
- 研发投入占营收 ≥ 5%（科技类）

**警惕**：
- 行业天花板快到了的"成长股"（比如已经做到行业第一且市占率 > 30%）
- 收入靠并表推高但净利润没增长
- 现金流为负的"成长"

**持仓周期**：6-24 个月

### 4.3 交易型（利弗莫尔 / 江恩 / 现代量化）

**信号组合**：
- 趋势：20 日均线 > 60 日均线 > 120 日均线（多头排列）
- 动量：RSI(14) 在 40-70 之间，不处于超买
- 量能：突破时放量到近 20 日平均的 1.5 倍以上
- 形态：箱体突破 / 杯柄形态 / 阶梯上涨

**严格止损**：-5% 到 -8%，不容协商
**严格止盈**：目标收益 = 止损幅度 × 2 或 × 3（盈亏比）

**持仓周期**：数日到数周

### 4.4 A 股特有需要关注的

- **北向资金**：持续净买入 + 持股创新高是强信号
- **龙虎榜**：机构净买入且非游资拉高出货
- **大小非解禁**：解禁前 1-2 周一般有压力
- **题材周期**：A 股题材炒作有明显的涨-调整-死亡循环，不要在题材尾声接货
- **市值优先**：V1 保守档只做流通市值 > 200 亿的票（流动性 + 抗操纵）

## 五、宏观与择时（有限择时，不择"涨跌"）

### 5.1 不要做的

- 不要预测"明天大盘涨不涨"——顶级经济学家都做不准，何况你我
- 不要全仓押注"指数会见顶/见底"
- 不要把宏观判断当做个股决策的唯一依据

### 5.2 可以做的

- **估值分位**看大盘贵不贵：沪深 300 PE 分位 > 80% 时降仓
- **M2 - 社融增速差**：领先股市 6-9 个月
- **十年期国债收益率**：急速上行对股市是逆风
- **风格切换**：大盘/小盘、价值/成长、周期/消费的相对强弱可以观测但不过度使用

### 5.3 反脆弱（塔勒布）

- 不要追求"平滑的稳定收益"——看起来稳的东西通常隐藏着尾部风险
- **适度多样化**：5-10 只股票分散，再多就变成拟指数，再少就暴露个股风险
- **准备黑天鹅资金**：10-20% 现金 + 少量长期看涨期权（A 股难做，可用股指期货简化）

## 六、行为金融 · 常见偏误自检

每月做一次自检，发现 3 条以上命中就暂停交易 1 周。

- [ ] 确认偏误：只看支持我持仓的信息，忽略反面证据
- [ ] 锚定效应：反复提及买入成本，忽略当前价值
- [ ] 处置效应：卖盈利的，留亏损的
- [ ] 过度自信：最近赚钱后开始重仓、加杠杆
- [ ] 从众效应：跟风热门话题 / 听大 V 推荐
- [ ] 最近效应：用最近 3 个月的经验推断未来
- [ ] 心理账户：把不同账户的钱当作不同性质（其实都是你的钱）
- [ ] 赌徒谬误：连跌 5 天"该涨了"

## 七、A 股特殊经验（实战派总结）

这些不是经典教科书内容，但 A 股市场确实有效：

### 7.1 时间窗口
- **年初**（1-2 月）：常有春季躁动，题材股机会多
- **3-4 月**：年报季，业绩暴雷频出，谨慎
- **5-6 月**：震荡，MSCI 调整可能带来外资流入
- **7-8 月**：中报季，预告阶段机会多
- **9 月**：历史上比较"毒"
- **10 月**：十月红（看政策风向）
- **11-12 月**：机构排名战，容易拉抬重仓股

### 7.2 量价关系口诀
- 价涨量增：健康上涨
- 价涨量缩：背离，警惕
- 价跌量增：空方占优
- 价跌量缩：止跌可能
- 放天量长阴：警惕主力出货
- 天地长阳：情绪反转可能

### 7.3 板块轮动大致规律
- 政策周期：基建 → 地产 → 消费 → 科技
- 经济周期：金融 → 周期 → 消费 → 成长
- 别在一个板块都涨完的时候进

## 八、总体纪律 · 如果只能记住 10 条

1. **保住本金。** 亏 50% 要涨 100% 才能回本。
2. **设置止损。** 不止损的人早晚被市场抬出去。
3. **不加亏损仓。** 反人性但救命。
4. **分散但不过度。** 5-10 只足够。
5. **只在自己理解的领域操作。** 不懂半导体就别追半导体。
6. **关注基本面。** 技术面决定买点，基本面决定持有多久。
7. **敬畏市场。** 市场永远可以比你预期更不理性。
8. **保留现金。** 永远至少 10%。
9. **远离杠杆。** 尤其是 A 股这种涨跌停制度。
10. **承认自己会错。** 错了就认，不要和市场较劲。
